# FIREmini

财务自由计算器，支持完整表单和逐页引导。两种填写方式共用参数，可以估算达到目标资产的时间，或反推目标年份所需的储蓄。

## 运行与测试

页面为静态 HTML、CSS 和 JavaScript，直接打开 `index.html` 即可使用。无需构建，运行时不依赖 CDN。

本地预览：

```sh
npm start
```

访问 `http://127.0.0.1:8765`。

自动化测试需要 Node.js 18 或更新版本：

```sh
npm ci
npm test
```

jsdom 仅用于测试表单交互，不参与生产页面运行。

修改 JavaScript 或 CSS 后，运行 `npm run assets` 更新页面中的资源内容指纹，再运行 `npm test`。发布时一起提交资源文件和 `index.html`，避免浏览器把新界面与缓存的旧计算脚本混用。

## 功能

- 按可存金额预测达成时间，或按目标年份反推所需储蓄。
- 引导中的金额可按月或按年填写，切换周期自动换算。
- 先设置通胀，再设置新增储蓄是否按通胀递增。
- 购房首付、纯商贷、纯公积金和组合贷款。
- 商贷与公积金分别计算等额本息月供，可设置不同还款期限。
- 收益率与通胀的比较、资产配置参考、提取率说明。
- 结果图表支持按期查看金额，参数变更后保留并标明旧结果。

答案仅保留在当前页面会话中，刷新后恢复初始值。

## 默认利率来源

截至 2026 年 10 月 5 日核对：

- 商贷默认 3.50%，参考[2026 年 9 月 5 年期以上 LPR](https://www.pbc.gov.cn/zhengcehuobisi/125207/125213/125440/3876551/2026092008384254324/index.html)，不代表具体银行执行利率。
- 公积金按[国管公积金贷款利率表](https://www.zzz.gov.cn/html/ywzn/dkyw1/18947.html)设置。首套 5 年及以内为 2.10%，超过 5 年为 2.60%；二套分别为 2.525% 和 3.075%。
- 利率均允许修改。公积金利率在自动状态下随套数和期限更新，手动修改后不再覆盖，点击恢复按钮可重新启用自动设置。
- 默认利率不会自动联网更新，维护时需同时检查计算器默认值、表单默认值、页面说明和来源日期。

## 计算约定

- 起点为起始年 1 月 1 日，目标年份指该年 1 月 1 日。
- 投资收益使用有效年收益率，按月模式换算为等效月收益率；房贷按合同年利率除以 12 计算月利率。
- 每期末计入新增储蓄并扣除购房现金流，记录下一期初余额。
- 按年模式将全年首付和月供汇总至年末；按月模式从购房当月末还款。
- 储蓄为支付生活费后、支付本计划首付和房贷前的结余。
- 公积金可贷额度由用户填写，工具不判断贷款资格。
- 组合贷款两部分分别到期，首付只扣一次。
- 未计房屋市值、装修税费、财政贴息和退休后资金提取。
- 负余额继续按设定收益率模拟，并提示资金缺口；不代表可以按该成本实际借款。

## 文件

- `fire-calculator.js`：计算引擎和贷款现金流。
- `fire-plan.js`：共享参数、单位转换、分支和输入校验。
- `app.js`：主表单、引导、结果和 SVG 图表。
- `styles.css`：桌面与移动端样式。
- `tests/`：计算与 DOM 交互回归测试。
